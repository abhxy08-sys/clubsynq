## Certificates integration (Google Sheets + n8n)

This project includes a small server endpoint that allows authenticated admins to append certificate requests to a Google Sheet. Configure the frontend to call this endpoint by setting environment variables in your React app.

Create a `.env` in the project root (for development) with:

REACT_APP_API_URL=http://localhost:4000
REACT_APP_ADMIN_SECRET=your-admin-secret

Restart the dev server after changing env variables.

Use the Organization page UI to fill certificate details and press "Save & Queue Certificate" to write to the sheet. Then configure an n8n workflow to poll the sheet and send certificates.

### Client-side Google Sheets (no server)

You can also let admins sign in with Google from the app and append rows directly to a Google Sheet (no server required). Set these env vars in your React app:

REACT_APP_GOOGLE_CLIENT_ID=your-google-oauth-client-id
REACT_APP_GOOGLE_SHEET_ID=your-google-sheet-id
REACT_APP_GOOGLE_SHEET_NAME=certificates

When configured, the Organization page "Save & Queue Certificate" button will prompt the admin to sign in and append the row to the sheet directly.
